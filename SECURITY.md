# Security Policy

## Supported Versions

Security fixes and patches are applied to the active release and development branches:

| Version | Supported |
|---|---|
| Latest Release (v1.3.x) | Yes |
| Main Branch (`main`) | Yes |
| Beta Branch (`beta`) | Yes |
| Older Versions (< v1.3.0) | No |

---

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Tide Island Extended (such as PAM authentication bypass, privilege escalation, or socket permission leaks), please **do not open a public issue**.

Instead, please report it privately:

1. Use GitHub's **[Private Vulnerability Reporting](https://github.com/Bimbok/Tide-island-extended/security/advisories/new)** feature on the repository.
2. Or contact the maintainer directly via GitHub profile contact information.

Please include:
* Description of the vulnerability and its potential impact.
* Steps to reproduce or proof-of-concept.
* Compositor and distribution environment details.

We appreciate your responsible disclosure and will address confirmed vulnerabilities promptly.
